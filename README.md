# H&G Armory 中文汉化版

二战射击游戏《英雄与将军》(Heroes & Generals) 武器数据库和对比工具的中文本地化版本。

## 致谢

本项目的原始工具由 [tzm13](https://github.com/tzm13) 开发制作，原项目地址：[hng-armory](https://github.com/tzm13/hng-armory)

本人仅在此基础上制作了中文本地化翻译，所有核心功能和数据均来自原作者的工作。

## 功能

- 武器数据面板：查看所有武器的详细属性（伤害、射速、后坐力、散布等）
- 武器列表：浏览所有武器并按阵营、类别筛选
- 武器对比：选择多把武器进行详细数据对比
- 弹道曲线：可视化伤害随距离的衰减
- 后坐力模式：展示武器后坐力轨迹

## 使用方法

直接在浏览器中打开 `index.html` 即可使用，无需服务器。
