# H&G Armory 中文汉化版

二战射击游戏《英雄与将军》(Heroes & Generals) 武器数据库和对比工具的中文本地化版本。

## 致谢

本项目的原始工具由 [tzm13](https://github.com/tzm13) 开发制作，原项目地址：[Github-hng-armory](https://github.com/tzm13/hng-armory),原项目现成网页:[hng-armory](https://hng-armory.top)

本人仅在此基础上制作了中文本地化翻译，所有核心功能和数据均来自原作者的工作。

## 功能

- 全站中文界面：采用 FPS 游戏通用术语翻译（伤害、射速、散布、后坐力、命中部位等）
- 武器数据面板：查看所有武器的详细属性（伤害、射速、后坐力、散布等）
- 武器列表：浏览所有武器并按阵营、类别筛选
- 武器对比：选择多把武器进行详细数据对比
- 伤害曲线：可视化伤害随距离的衰减（原弹道曲线）
- 伤害联动：伤害与每秒伤害随命中部位（头部/躯干/腿部/手臂）和敌方重型武装等级（铜/银/金）实时变化，数值四舍五入取整
- 精度后坐力与伤害距离：拖动距离滑块，实时显示散布偏移范围、子弹命中目标时间与对应伤害
- 后坐力模式：展示武器后坐力轨迹
- 载具数据面板：查看所有载具的详细属性（生命值、装甲、速度、部署成本、野战维护载荷等），含装甲厚度显示（车体/炮塔各部位）
- 载具列表与对比：浏览、筛选并按阵营排序所有载具，支持多载具详细数据对比
- 阵营/类别实时筛选：武器与载具列表、对比视图均支持按阵营和类别实时筛选
